# GlowUp

A polished front-end personal growth dashboard built with plain HTML, CSS and JavaScript.

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Recommended: install the **Live Server** extension, then right-click `index.html` → **Open with Live Server**.

No npm or backend is required.

## Included
- Dashboard with progress
- Habit tracker with XP
- Add habits
- Goals with progress controls
- Mood check-in
- Achievements
- Dark mode
- LocalStorage persistence
- Responsive design
